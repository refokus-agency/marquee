Marquee Component Demo

Resize the window to see the component dynamically add/remove clones. Cloning is debounced (150ms). The entire [data-marquee] wrapper is cloned, not individual items.

Default: draggable: false — enable drag per-instance via data-marquee-draggable="true" or the JS option.

1. Left-to-Right (default)

Default direction. No attributes needed beyond data-marquee. CSS: container overflow: hidden, track display: flex; width: max-content.

Clones: calculating...

2. Right-to-Left

Set data-marquee-direction="rtl" on the wrapper. Same horizontal CSS as LTR.

3. Vertical — Top-to-Bottom & Bottom-to-Top

Set data-marquee-direction="ttb" or "btt" on the wrapper. Vertical CSS: container needs a fixed height + overflow: hidden; track uses flex-direction: column; height: max-content.

4. Custom Speed

data-marquee-speed="3" runs at 3× the default rate.

5. Pause on Hover

data-marquee-pause-on-hover="true" pauses the animation when the mouse enters the container.

Hover over the logos to pause the animation

6. Draggable

data-marquee-draggable="true" enables drag and touch interaction. Draggable is off by default — you must opt in per marquee.
