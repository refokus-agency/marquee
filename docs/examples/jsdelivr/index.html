Marquee — jsDelivr Demo

This page loads the package straight from jsDelivr. There is no build step, no bundler, no import map and no separate GSAP tag — the /+esm endpoint resolves the peer dependency for you.

Already loading GSAP yourself? Then don't use /+esm here. It bundles its own copy of GSAP, so you would end up with two GSAP instances — Observer registers against one core while your tweens run on the other, and drag silently stops working. In that case load marquee.browser.js directly and map gsap to your own copy with an import map.
